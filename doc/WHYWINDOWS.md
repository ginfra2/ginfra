## Why support windows?

The majority of modern cloud development is done on and for *nix, but in its first year, most of this has been primarily 
done on windows.  My Macbook is watching me and weeping while I type this.  But why?  The folks I'm helping out with 
this are all using windows for development.  I needed to make sure it works first on windows and then in production *nix, 
which is where they will eventually go live.  (I think I have finally talked them into using EKS, but we shall see.) 

That said, all current development is done on Ubuntu and Macos, with Windows being tested secondarily.
